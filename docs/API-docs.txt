4. QUẢN LÝ DANH SÁCH NGƯỜI DÙNG (CHỈ ADMIN) - CÓ PHÂN TRANG
-----------------------------------------------------------
- Endpoint: /api/v1/users
- Method: GET
- Auth: Required (access-token, role: ADMIN)
- Payload JSON: null
- Query Param: 
    - page: Số trang (mặc định 1)
    - limit: Số lượng mỗi trang (mặc định 10)
    - search: Tìm theo tên, email, sđt (optional)
    - role: Lọc theo vai trò (ADMIN, PLAYER, COURT_OWNER) (optional)
- Response JSON (200 OK):
{
    "statusCode": 200,
    "message": "Lấy danh sách người dùng thành công",
    "data": {
        "users": [ ... ],
        "pagination": {
            "total": 150,
            "page": 1,
            "limit": 10,
            "totalPages": 15
        }
    }
}
